# Security Policy

## Supported Versions

Only the latest published release receives security fixes.

## Reporting a Vulnerability

[Report vulnerabilities privately through GitHub Security Advisories](https://github.com/puwenfu/CodexUsageBar/security/advisories/new).
Do not include credentials, account identifiers, raw Codex responses, logs, or
unredacted screenshots in a public issue.

If private reporting is unavailable, contact the maintainer through the
[GitHub profile](https://github.com/puwenfu) before sharing technical details.
