# CodexUsageBar 1.2.4

This maintenance release improves the compact Windows 11 taskbar menu and the
public release pipeline.

## Highlights

- Menu icons are 80% of their previous visual size while menu hit targets remain unchanged.
- Nested theme menus prefer the right side and use the standard WPF popup contract.
- Public download and private security-reporting links now point to the maintained repository.
- The self-contained executable is compressed, reducing extracted disk usage from about 188 MB to 74 MB.
- CI now builds and validates the final release candidate.

## Requirements

- Windows 11 with the primary taskbar at the bottom.
- The self-contained .NET 8 executable does not require a separately installed .NET runtime.
- A working, signed-in Codex App or Codex CLI installation.
