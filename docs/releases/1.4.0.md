# CodexUsageBar 1.4.0

This feature release makes CodexUsageBar easier to keep available and position
around a Windows 11 desktop.

## Highlights

- A persistent system-tray entry opens the same settings menu even when the
  widget is using another display surface.
- Display-position controls can prefer the taskbar, the desktop Codex sidebar,
  or tray-only mode, with independent horizontal adjustment.
- Theme, placement, and offset choices now persist across restarts.
- Clicking outside the right-click menu reliably closes it while submenu
  interaction remains intact.
- Startup controls now fail safely when Windows denies access.

## Download

Download `CodexUsageBar_1.4.0_win-x64.zip` and verify it against the accompanying
`SHA256SUMS.txt`.

The executable is unsigned. Windows may display an Unknown Publisher or
SmartScreen warning. Verify the SHA-256 checksum before running it.

## Requirements

- Windows 11 with the primary taskbar at the bottom.
- A working, signed-in Codex App or Codex CLI installation.
