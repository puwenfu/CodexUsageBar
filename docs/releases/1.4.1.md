# CodexUsageBar 1.4.1

This release brings the remaining Codex quota directly into the Windows system
tray so the current allowance stays visible even when the taskbar widget is
hidden or placed elsewhere.

## Highlights

- The tray icon now shows the five-hour quota percentage inside a live progress
  ring.
- When five-hour quota data is unavailable, the icon falls back to the weekly
  quota instead of showing stale or misleading data.
- The tray meter follows the selected color theme and Windows light or dark
  appearance.
- The application icon and theme previews now match the tray meter
  presentation.

## Download

Download `CodexUsageBar_1.4.1_win-x64.zip` and verify it against the accompanying
`SHA256SUMS.txt`.

The executable is unsigned. Windows may display an Unknown Publisher or
SmartScreen warning. Verify the SHA-256 checksum before running it.

## Requirements

- Windows 11 with the primary taskbar at the bottom.
- A working, signed-in Codex App or Codex CLI installation.
