# CodexUsageBar 1.4.2

This release makes Codex-sidebar placement stable across window sizes and keeps
the quota meter out of the way when Codex is not the active application.

## Highlights

- The sidebar widget now aligns to the real Codex client area, avoiding the
  invisible resize frame that previously shifted it in maximized windows.
- Windowed and maximized Codex layouts share the same placement rule while
  preserving the selected horizontal offset and widget size.
- Sidebar placement falls back to the system tray whenever its Codex window is
  not active.
- The background track is lighter across the widget, theme previews, and tray
  icon so the remaining-quota arc is easier to read.

## Download

Download `CodexUsageBar_1.4.2_win-x64.zip` and verify it against the accompanying
`SHA256SUMS.txt`.

The executable is unsigned. Windows may display an Unknown Publisher or
SmartScreen warning. Verify the SHA-256 checksum before running it.

## Requirements

- Windows 11 with the primary taskbar at the bottom.
- A working, signed-in Codex App or Codex CLI installation.
