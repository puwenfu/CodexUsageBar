# CodexUsageBar 1.2.1

CodexUsageBar is now ready as an MIT-licensed open-source Windows 11 taskbar
widget.

## Highlights

- A compact, consistent taskbar menu with theme, startup, debug, and About
  controls.
- An option to hide the five-hour meter while keeping the weekly meter centered.
- Local preference persistence without copying Codex credentials or raw quota
  responses.
- Reliable taskbar recovery across Show Desktop and Explorer recreation.

## Requirements

- Windows 11 with the primary taskbar at the bottom.
- The self-contained .NET 8 executable does not require a separately installed .NET runtime.
- A working, signed-in Codex App or Codex CLI installation.
