# CodexUsageBar 1.2.4 release acceptance

## Verified

- Built with the project-pinned .NET SDK 8.0.423.
- All 267 .NET tests and 37 release-script tests passed.
- The self-contained executable reports product version 1.2.4 and file version 1.2.4.0.
- The release ZIP contains only the executable and four required distribution documents.
- The ZIP and executable match `SHA256SUMS.txt`; no temporary files remain in the release directory.
- The final executable starts in the real Windows 11 session, remains responsive, and enforces one running instance.
- The widget is visible at the far-left of the primary taskbar, stays inside the taskbar rectangle, and shows its hover details.

## Automation boundary

The Windows automation runtime can capture the embedded taskbar widget but
cannot target that Explorer-owned child window independently for injected
right-click input. Menu icon sizing and submenu placement/contract are covered
by the WPF contract tests; the final right-click, submenu hover, and
outside-click-close sequence remains a manual interaction check.
